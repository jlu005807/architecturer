# 架构模板输出规范

> 当用户要求对某个系统进行完整架构分析时，按此模板输出。
> 模板中 `[方括号]` 内容为待填充项，遇到无法确定的部分**必须向用户询问确认**，不要自行臆断。

---

## 交互规则

在填充模板过程中，以下信息**必须向用户确认**而非自行假设：

| 类别 | 需要询问的典型问题 |
|------|-----------------|
| 规模与流量 | 当前/预期用户量？峰值 QPS？日活多少？ |
| 质量属性优先级 | 延迟、可用性、成本哪个最优先？能容忍什么程度的不一致？ |
| 约束条件 | 团队多大？多久上线？预算多少？有无合规要求？ |
| 业务特征 | 读写比大概多少？数据增长预期？失败的代价有多严重？ |
| 技术偏好 | 有倾向的技术栈？已有哪些基础设施/中间件可复用？ |

**原则**：宁可多问一句，不要基于错误假设做出架构决策。
